# mini-spring 官网重构 · 线框图规范

> 版本 v1.0 · 配套 `site-redesign-spec.md`
> 范围：38 个页面（19 个条目 × 双语）的**区块级线框** + 17 类组件的**全状态线框**
> 线框为**规格级**（标注尺寸、层级、间距），不是美术稿。数值全部取自设计令牌，实现时直接照此落地。

---

## 阅读说明

线框使用等宽字体绘制，中文按双宽对齐。字符约定：

| 字符 | 含义 |
| --- | --- |
| `┌ ┐ └ ┘ ─ │ ├ ┤ ┬ ┴` | 区块、卡片、表格边框 |
| `▌` | 左侧指示条（当前项 / 强调竖条） |
| `── 标题 ──` | 区块分隔与命名 |
| `•` | 列表项 |
| `● ○` | 时间轴已完成 / 待开始节点 |
| `▾ ▴ ▸` | 展开 / 收起 / 折叠箭头 |
| `[ ]` | 按钮、徽章、输入框 |
| `→` | 行动引导链接 |

尺寸统一使用 `px`，间距遵循 8px 基准栅格。

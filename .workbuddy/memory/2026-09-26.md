## 重构实施（第三轮，代码落地）

**结果**：构建通过，**40 个 HTML 页面**（19 条目 × 双语 + 404 双语），最终校验全绿。

**校验基线（最终）**
- 链接：40 页 / 1456 个锚点 → **0 失效**
- 运行时：40 页 → 0 console 错误、0 失败请求、0 破图、每页均有 h1 与标题
- 响应式：15 个断点（1440→360）× 40 页 → **0 横向溢出**

**主题基建**（`docs/.vitepress/theme/`）
- `tokens.css` 四组设计令牌（色彩/字体/间距/圆角描边），明暗双份；`components.css` ~2200 行
- 14 个全局组件：`DsHero / DsStatBar / DsFigureGallery / DsClassIndex / DsRoadmap / DsAccordion / DsSegmented / DsCompare / DsCodeGlance / DsDocHead / DsStructure / DsErrorTable / DsFaq / Ds404`
- 数据模块 `data/classes.ts`（127 类，与源码 comm 比对零差异）、`data/errors.ts`、`data/faq.ts`

**踩坑与修复（都是真实缺陷，非风格问题）**
1. **markdown-it HTML block(type 6) 遇空行即终止** → 块内空行会让后续缩进标签渲染成 `<pre><code>`，首页卡片变代码、栅格崩塌。已修 8 文件 58 行，并加 `scripts/check-html-blocks.mjs` 挂到 `prebuild`。
2. **原始 HTML 里的 `href="/xxx"` 不会被 VitePress 补 base** → base=`/mini-spring/` 下直开/新标签页 404。共 **41 处**（15 个 md）+ 组件若干 + 书籍封面 `src` 4 处。
   - 方案：新增 `theme/siteHref.ts`（补 base；未开 `cleanUrls` 时补 `.html`，与 VitePress 自身链接形式一致），全局属性 `$href` 供 markdown 用，组件内 `import { siteHref }`。
   - 另加 `scripts/check-internal-links.mjs` 守卫，同样挂 `prebuild`（`npm run check`）。
3. **`en/index.md` 用 `./en/xxx`** → 从 `/mini-spring/en/` 解析成 `/mini-spring/en/en/xxx`，10 处全挂。改为 `./xxx`。
4. **VitePress 的 404 由内置 `NotFound.vue` 渲染**，自研 `Ds404` 从未生效。正解：默认主题 `Layout` 会把 `#not-found` 插槽透传给 `VPContent`，在该插槽挂 `<Ds404 />` 即可（插槽有内容就不再回退内置组件）。另补 `en/404.md`，因为语言切换会指向 `en/404.html`。
5. **`style="grid-template-columns: repeat(5,1fr)"` 内联样式压制所有媒体查询** → 贡献页 5 步流程在窄屏溢出。改为 `.ds-steps--5` 类 + 断点。
6. **`1fr` 的隐式最小宽度是 min-content** → 文档页内容区仅 ~620px 时三列卡片撑破栅格。改用 `repeat(N, minmax(0, 1fr))`。
7. 其他：`.ds-changes code` 长类名折行、`.ds-segmented` 窄屏等分整宽、英文站名在 768–900px 撑破导航（该区间隐藏站名文字只留 logo）、`Compare.vue` 的 scoped 样式挪到全局（markdown 手写表格吃不到 scoped）。

**环境坑**
- Git Bash(MSYS) 会把命令行里的 `/xxx` 参数改写成 Windows 路径 —— 传 URL 路径给 node 脚本必须加 `MSYS_NO_PATHCONV=1`。
- `vitepress dev` 会锁住 `dist/`，会让下一次 `build` 的删除步骤失败；构建前务必先停掉。
- 不能用 Bash 调 `powershell.exe`（安全策略拦截），改用 PowerShell 工具。

**验证脚本（临时，在 C:/tmp）**：`brokenlinks.mjs`（锚点解析+文件存在性）、`verify.mjs`（运行时健康 + 15 断点溢出）、`shot.mjs`（双主题截图）

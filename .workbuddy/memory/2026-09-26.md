## 线框级别细化（第二轮）

**产出**：`design/wireframes.md`（1452 行 / 87K 字符），17 章 + 附录
- 第 1–12 章：页面级线框，覆盖全部 19 个页面条目（首页 / 快速开始 3 页 / 架构总览 / 对比 / 类参考 / 路线 / 文档页骨架 / FAQ / 更新日志 / 关于 / 贡献 / 404）
- 第 13–15 章：导航结构（顶部导航 6 项含 2 个下拉、侧栏 6 组含折叠与抽屉、页脚 4 列矩阵）
- 第 16–17 章：组件级全状态线框（按钮 / 特性卡 / 提示块 / 代码块 / 表格 / 徽章 / 分段控件 / 折叠面板 / 时间轴）
- 附录：19 页面清单（路由 / 布局 / 内容宽 / 线框章节 / 新增或沿用）+ 12 类组件复用索引

**规模**：196 个线框区块、933 行线框、261 行规格表，宽度全部 82 视觉宽（零对齐异常）

**方法（可复用）**：
- 用 Python 脚本生成 ASCII 线框，`unicodedata.east_asian_width` 判 CJK 双宽，`fit()` 统一补齐/截断到固定视觉宽
- 核心渲染函数：`top/bot/row`（框）、`ruler`（区块分隔）、`grid`（横向卡片）、`table`（盒内表格）、`stack`（纵向堆叠）、`frame`（整体包裹）
- 关键教训：**表格与卡片必须用不同渲染函数**——早期误用横向 grid 渲染 3 列表格，导致行宽膨胀至 1000+ 视觉宽，必须用 `table()` 逐格拼接
- 每部分生成后立即校验行宽恒为 82，再合并，避免错误累积

**计数修正**：方案原写「20 → 34 页面」有误，已核实并统一为 **20 → 38 页面**（19 条目 × 双语）；新增条目实为 9 类而非 7 类。
